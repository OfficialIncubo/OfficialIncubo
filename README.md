# What I'm actively working on my open-source projects?

Well, some two of my beloved and fully-working standalone music visualizers I've been working for 4 years. Both of them are made for DJs, VJs, music listeners and such. Here's what I'm saying:

- **[BeatDrop Music Visualizer](https://github.com/OfficialIncubo/BeatDrop-Music-Visualizer)**: It's a standalone music visualization powered by a custom [MilkDrop](http://www.geisswerks.com/milkdrop/) engine, originally built as a plug-in for a popular music player called [Winamp](https://winamp.com/) for Windows. It features an expanded animated sprite/texture support (GIF, Video and Spout Input), FFT/Wave audio data shader functions, System Time/Date variables, extended custom shapes/waves limit, live speaker/microphone audio input, customized audio processing code and so much more! Made by contributors and me.

- **[fische music visualization for Windows](https://github.com/OfficialIncubo/fische-windows)**: A Windows port version of an original Linux-based music visualizer under the same name, [fische](https://web.archive.org/web/20200801073714/http://26elf.at/musicviz/) ([source code](https://github.com/maysl/fische)). It provides much and much features, maintaining the same functionality: [Spout](https://spout.zeal.co/) output for visual sending, adjustable audio sensitivity, settings dialog, ASIO support, buttery smooth visuals and more; packed in just ONE executable. Made by a sole developer, almost mostly vibecoded with hard-tweaks and testing with trial and error.

Some note: both of these products requires Windows OS machine with necessary requirements, such as DirectX and runtime packages. As I'm a Windows guy, I had much experience on it.
Due to my other personal work or non-allocated time, the active development will maintain slower and a gradual-pace. Whatever, if I'm having a full energy, it will move (a little bit faster).
